# Sanchit Jha — Portfolio

Personal portfolio of Sanchit Jha, a backend & full-stack developer.

The application lives in **[`web/`](./web)** — a Next.js 15 app.

```bash
cd web
npm install
npm run dev      # http://localhost:3000
```

See **[`web/README.md`](./web/README.md)** for content editing, environment
variables, and deployment instructions.

## Deploy (Vercel)

Import this repo on Vercel and set the project's **Root Directory to `web`**
(Settings → General → Root Directory). Next.js is auto-detected. Add the
environment variables listed in `web/.env.example`, then deploy.
